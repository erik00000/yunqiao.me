# 插件检查与历史区域迁移

本轮在本地检查并修复插件安装、启停、配置、运行状态与历史迁移流程。未发布新版本，未修改真实 ChatGPT / Codex 配置或历史。

## 插件检查范围

- 桌面增强：32 项内置增强的状态与兼容限制、5 个随附拓展包的配置和加载、CDP 连接及断开后的清理。
- 原生市场：公开库与完整库目录、单包下载校验、安装版本、更新、下架项目管理、注册文件与安装记录一致性。
- 网关中间件：5 项内置能力与自定义 JavaScript 的保存校验、执行结果、失败保护和运行状态。
- 资源工作台：MCP、Skills、提示词与原生插件入口，读取失败后的界面状态。

桌面扩展后端 27 项检查通过，含隐藏 Electron 中五个随附包的实际功能，见 [扩展后端审计](EXTENSION-BACKEND-AUDIT.md)。界面修复明细与 16 项浏览器检查见 [插件界面审计](PLUGIN-UI-AUDIT.md)。网关中间件 21 项隔离回归在普通 Node 与 Electron 内嵌 Node 中均通过，修复了以下问题：

1. 无效返回值或执行中抛错可能破坏请求；现在只接受有效结果，失败保留进入该插件前的请求。
2. 异步返回、未返回的 Promise 拒绝和微任务死循环可能影响主进程；现在在当前脚本执行期间识别其 VM 内创建的 Promise 并处理拒绝，同步插件不接受异步任务，微任务也在同一超时范围执行。
3. 同一插件 ID、同一更新时间可能复用旧代码或旧参数；缓存改为校验实际代码与参数内容。
4. 敏感词只处理首个命中词，且直接替换序列化 JSON 可能破坏字段；现在处理全部文本命中，保留协议字段、工具标识及工具输入的键。
5. 坏脚本语法和无效内置参数原来可以保存；现在保存前校验，已有坏插件仍可停用。错误信息不回显请求正文。
6. “已启用”不能代表实际成功；新增等待请求验证、最近执行成功、失败及主动拦截状态，保存、删除或成功导入新配置后清除旧结果。对返回的 token 上限、stop、reasoning 等参数也执行校验，无效结果不会发给上游。

配置与市场共享的多文件事务补上逐文件复核和回滚冲突保护：只撤回本操作写入的内容，外部新增修改保留并明确提示文件路径；回滚其中一项失败仍继续处理其他项。损坏备份的解析错误使用固定提示，避免回显内容。对应 14 项故障测试通过。

## 历史迁移

入口为 **历史会话 → 批量修复历史 / 区域迁移**。下拉选择原生 `model_provider` 来源及目标区域，预览后勾选部分或全部会话。目标按真实 TOML 根配置与旧式活动 profile 表解析，包括中文、点号标识；历史中已删除配置的旧来源仍可迁出。新版 CLI 参数选择的独立 profile 文件尚不自动识别。

迁移同时处理 JSONL 元数据、原生 `threads` 及本地主机目录。保留正文、会话 ID、模型内容和归档状态，支持按批次恢复。来源以原生索引为准；缺失文件、重复身份、索引冲突、客户端未退出及预览过期会阻止写入。

31 项历史后端回归、18 项原生消息索引回归、7 项界面到真实隔离 SQLite 的闭环检查通过。具体语义、操作和边界见 [历史区域迁移](HISTORY-PROVIDER-MIGRATION.md)。

## 验证边界

插件市场索引覆盖数千个第三方项目，本轮验证市场机制与代表性安装流程，并未逐个执行所有插件或验证它们的外部服务。五个随附包的实际运行检查使用受控 Electron 客户端；真实官方发行版的私有接口仍需逐版本联调。尚未适配的增强继续明确禁用，界面展示具体原因。

历史迁移调整的是本地供应商归属，不能解密其他账号的推理上下文，也不能保证不同服务可以继续使用同一段加密状态。全部迁移测试使用临时文件与数据库。
