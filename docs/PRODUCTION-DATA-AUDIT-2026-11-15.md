# 正式数据与发布资源清理

本次检查桌面正式代码、默认供应商目录、PHP 后台、手机伴侣及 Windows 发布资源，区分实际业务配置、未填写状态与仅用于验证的测试样例。

## 已清理

- 删除不再使用的演示数据生成脚本。逐项确认工作区演示目录只有生成数据后，删除 19 个文件：5 家演示供应商、6 个假密钥、2 个路由组、假连接状态及 14 天共 170 条模拟用量。未读取或删除客户真实数据目录。
- 四个需要自行填写地址的供应商模板（Azure 与三类中转协议）不再填入示例 API 地址或模型。新建模板保持待填写；旧远端目录和缓存中的同类占位自动清空，缺少实际地址时不发起模型请求。已有用户供应商配置保持原值。
- 移除包元数据中的虚构联系邮箱，以及界面里会让人误以为可直接使用的固定地址、旧安装包版本和未经核实的能力示例。
- 新部署的后台保持“尚未发布”，不生成虚构的首个版本；未发布时客户端提示原因。会员接口未返回有效余额时保持未知，不显示假零余额。
- 正式包的随附资源从 217 项中排除 21 个 JavaScript 测试文件和 8 个未参与运行的 Rust 参考源码，保留 188 项运行资源与许可信息。完整源清单仍逐项校验，发布清单单独生成；验包拒绝遗漏、篡改或多带测试文件。
