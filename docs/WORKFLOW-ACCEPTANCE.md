# 本轮客户端功能验收

本轮针对目录与更新、插件、历史区域迁移、本机配置发现和官方账号共存。此前运行的早期 0.6.0 包不包含这些新增流程；本次调试包在侧栏显示「调试」，在「系统设置 → 版本更新」显示构建时间。

| 功能 | 使用入口与实际行为 | 验证 |
| --- | --- | --- |
| 官方目录自动同步 | 设置页隐藏目录地址与开关；启动获取、缓存、失败回退，旧配置也开启自动模型同步 | 更新 21 项、目录异常 9 项、设置迁移 6 项 |
| GitHub 优先、官网备用 | 版本更新自动选择当前平台正式安装包；官网备用检查版本，不提供降级下载 | 更新后端 21 项、更新界面 18 项 |
| 本机配置自动读取 | 启动、每 30 秒及窗口重新获得焦点时扫描；API 配置去重加入「我的供应商」，官方登录单独展示，保留手工编辑/删除 | 配置发现、实际打包客户端界面验收 |
| 官方账号与中转共存 | 「客户端接入 → ChatGPT 桌面版 / Codex CLI → 保留官方账号并与第三方模型共存」，官方和第三方请求分别认证 | 共存网关 19 项、配置 20 项、真实 Codex CLI 隔离请求 |
| 历史区域迁移 | 「历史会话 → 批量修复历史 / 区域迁移」，选择来源/目标，预览、勾选、备份迁移，可恢复 | 历史 31 项、索引 18 项、真实界面与 SQLite 7 项 |
| 插件检查与修复 | 安装/更新/启停/配置/运行状态；5 个随附包实际加载；补全会话查询与增量事件接口 | 扩展 27 项、会话查询 7 项、插件界面与中间件回归 |

本轮额外修复：向导有默认模型时仍同步、有列表时仍可手填；供应商保存成功与模型同步失败分别显示；目录后台更新后所有页面跟随刷新；慢模型请求不覆盖并发编辑或复活已删除的供应商。新增向导/目录界面 11 项、供应商同步界面 7 项、模型同步并发 6 项验证。

所有写入类验收使用临时配置、假账号和本地模拟服务。未改写用户真实 OAuth、配置或对话，也未执行真实账号推理计费。真实 CLI 验收证明本机安装的客户端能读取配置和走通请求，不代替所有 ChatGPT 桌面发行版的在线兼容验证。

插件仍有明确不支持的能力：侧聊分叉保存、微信同步、按上报用量压缩、浏览器请求标识和官方额度入口。这些入口保持禁用并显示原因，不能把市场收录数当作全部插件已实测。普通 ChatGPT 聊天版不具备编程客户端的第三方配置能力。

当前调试包与哈希见 [Windows 本地功能验收](LOCAL-VALIDATION-0.6.0.md)。启动前从托盘退出早期版本，避免单实例机制重新打开旧程序。
